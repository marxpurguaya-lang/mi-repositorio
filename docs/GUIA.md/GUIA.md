# Guía del Laboratorio 03

Esta guía explica de manera sencilla cómo realizar un trabajo colaborativo utilizando Git y GitHub.

## Objetivo del proyecto

El objetivo es aprender a trabajar con un repositorio compartido, realizar cambios y subirlos mediante Git.

### Herramientas utilizadas

- Visual Studio Code
- Git
- GitHub
- Navegador web

## Instalación

1. Instalar Git en el equipo.
2. Abrir Visual Studio Code.
3. Clonar el repositorio desde GitHub.
4. Entrar a la carpeta del proyecto.
5. Abrir el proyecto en Visual Studio Code.

Para comprobar los cambios se puede utilizar el comando `git status`.

## Tareas realizadas

- [x] Crear el repositorio.
- [x] Clonar el repositorio.
- [x] Realizar cambios en los archivos.
- [ ] Crear un Pull Request.

## Comandos principales

```bash
git clone URL_DEL_REPOSITORIO
git add .
git commit -m "Actualiza el proyecto"
git push origin main
```
